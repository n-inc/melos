# Governance

Melos is maintained as an n-inc open-source project.

## Roles

- Maintainers can review and merge pull requests, manage releases, triage
  issues, and update project policy.
- Contributors can open issues, discussions, and pull requests.

Current maintainer:

- [@kmagai](https://github.com/kmagai)

The maintainer list and release owner are tracked in [MAINTAINERS.md](MAINTAINERS.md).

## Adding Maintainers

Maintainers may invite regular contributors after they have demonstrated good
judgment in code review, release preparation, security hygiene, and issue
triage.

The expected path is:

1. recurring contributions through pull requests or reviews
2. ownership of a small area of the codebase or documentation
3. maintainer nomination by an existing maintainer
4. organization-level repository access update

## Decision Making

Small technical decisions can be made in pull requests. Larger changes to route
semantics, runtime support, security posture, or release process should be
documented in an issue or pull request before implementation.
