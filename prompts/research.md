## Melos 研究フェーズ

**PRD**: @PRD.md
**Progress file**: @{PROGRESS_FILE}

---

## 目的

PRD.mdの要件を実現するために、以下の調査を徹底的に行い、実装計画（PLAN.json）を作成する。

## 調査内容

### 1. コードベース調査

以下の観点でコードベースを調査し、`.melos/research/` に結果を保存する:

- **既存の実装パターン**: 類似機能がどう実装されているか
- **依存関係**: 変更が影響する範囲
- **テストパターン**: 既存のテストの書き方
- **設定・環境**: 必要な設定ファイルや環境変数

### 2. Webベストプラクティス調査

以下の観点でWeb検索を行い、`.melos/research/` に結果を保存する:

- **技術的なベストプラクティス**: 推奨されるパターンや実装方法
- **セキュリティ考慮事項**: 注意すべきセキュリティポイント
- **パフォーマンス最適化**: 推奨される最適化手法
- **類似実装例**: オープンソースでの実装例

## 出力形式

### research ファイル

各トピックごとに `.melos/research/{topic}.md` を作成:

```markdown
# {トピック名}

## 調査日時
{YYYY-MM-DD}

## 調査概要
{1-2文で要約}

## 詳細

### コードベース調査
{詳細な調査結果}

### Webベストプラクティス
{参照したURLと要点}

## 結論・推奨事項
{実装に活かすべきポイント}
```

### PLAN.json

調査結果を踏まえて、PLAN.jsonを作成/更新する:

```json
[
  {
    "id": "1",
    "description": "タスクの説明（調査結果を踏まえた具体的な内容）",
    "checks": [
      { "text": "検証項目", "type": "auto:jest", "passed": false }
    ],
    "passes": false
  }
]
```

### PROGRESS.md への記録

調査結果の要旨をPROGRESS.mdに記録（詳細はresearchファイルを参照）:

```
- {トピック}を調査
  - 詳細: .melos/research/{topic}.md
```

## 完了条件

以下が完了したら `<promise>RESEARCH_COMPLETE</promise>` を出力:

1. 必要な調査が全て完了
2. `.melos/research/` に調査結果を保存
3. PLAN.json を作成/更新
4. PROGRESS.md に要旨を記録

## 注意事項

- **徹底的に調査する**: 不明点は推測せず、調べる
- **詳細はresearchファイルに**: PROGRESS.mdには要旨のみ
- **既存のPLAN.jsonがある場合**: 調査結果を踏まえて必要なら更新
